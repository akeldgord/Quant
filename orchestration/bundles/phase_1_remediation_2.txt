B. What was built

Per orchestrator instruction argus-phase-1-remediation-002
(AUTHORIZED_ACTION: REMEDIATE_PHASE_1_ROUND_2_ONLY, APPROVES_PHASE: NONE),
all 12 audit findings were remediated with real production code and

1. **Finding #2, #5, #6, #9, #10** (`da74172`) — session-per-operation
   unit of work, atomic commitment derivation, durable parse ledger,
   pagination continuity, ledger immutability. `ReconciliationEngine`
   takes a `ReconciliationUnitOfWork` factory (`SqlReconciliationUnitOfWork`
   opens/commits/closes its own `AsyncSession` per atomic operation) instead
   of one shared session across every concurrent task. `commitment_observations`
   gains a database-generated monotonic `sequence` column, per-event
   `pg_advisory_xact_lock` serialization, full-same-level-state
   conflict validation (not just the first row), a `CommitmentAppendOutcome`
   (APPENDED/DUPLICATE_NOOP/REJECTED/FAILED) enum, and a durable
   `commitment_observation_rejections` audit table. Migration 0004
   revokes UPDATE on `chain_events`/`commitment_observations` from
   `argus_ingest` (append-only enforced at the database role layer,
   verified with the ingest role's own connection). A new durable
   `parse_attempts` ledger records every parse attempt in the same
   transaction as the watermark advance; a new `argus ingest reparse`
   sweep retries pending/failed events without rewriting raw evidence.
   `argus.db.errors.constraint_name()` fixes a real bug found this round
   (asyncpg wraps `constraint_name` two levels deeper than the naive
   `exc.orig` lookup) so only the exact expected constraint is ever
   treated as an idempotent dedup collision. Pagination now validates
   newest-first ordering and cross-page signature uniqueness (subsuming
   both immediate-repeat and multi-step cursor cycles).

2. **Finding #1, #3, #4** (`bccd2a2`) — explicit subscription
   acknowledgement, structured task supervision, finalization sweep
   wiring. `LiveChainStream.subscribe_wallet()` (an implicit async
   generator whose connect/subscribe/ack happened lazily on first
   iteration) is replaced by `open_subscription()`, a real `async def`
   that only returns once connect + subscribe-request-sent + a valid
   matching acknowledgement have all genuinely completed, returning a
   `StreamSubscription`. `WalletWatermark` tracks three independent
   recovery dimensions — `stream_health` (manager-owned via
   `mark_stream_ready`/`mark_degraded`, never touched by `reconcile()`),
   `reconciliation_ok` (new persisted column, owned exclusively by
   `reconcile()` — migration 0005), and clock health (computed live,
   never persisted) — with `wallet_live_state` always derived from all
   three; no single dimension can restore OK alone. `IngestionManager.run()`
   now races every supervised task against the stop condition; any
   unexpected completion marks every tracked wallet DEGRADED, cancels
   every sibling task, and raises `IngestionManagerFailure`, which the
   CLI catches and exits 1 on. A new `_run_finalization_sweep` background
   task actually calls `sweep_finalization()` on a configurable cadence
   (it previously existed but no production loop ever called it).

3. **Finding #7** (`494a9ba`) — typed canonical provider response
   models. New `argus.providers.models` (`TokenSnapshot`, `OhlcvCandle`,
   `OhlcvPage`, `ExecutableQuote`, `UnsignedOrderResult`, frozen
   dataclasses, `Decimal`/integer financial fields). `MarketDataProvider`/
   `ExecutionProvider` protocols and every adapter (DexScreener,
   GeckoTerminal, Jupiter) now return these instead of provider-shaped
   `dict[str, Any]`; probes assert `isinstance` against the canonical
   types instead of `dict`.

4. **Finding #8** (`18cab36`, extended `0943368`) — terminal usage
   outcome recorded after decode/validation. `send_with_usage()` now
   takes the adapter's own `process` step (raise_for_status + decode +
   contract validation) and records exactly one terminal outcome decided
   only once that step finishes: ok / http_error / rpc_error /
   contract_error / decode_error / transport_error / timeout (split from
   transport_error since `httpx.TimeoutException` is a materially
   different signal); cancellation is a `BaseException` so nothing is
   recorded for it. `HeliusRpcError` distinguishes a well-formed RPC
   error (`rpc_error`) from a malformed envelope (`contract_error`). A
   follow-up fix (`0943368`, found during this checkpoint's own
   acceptance-criteria review) makes a usage-recorder failure emit a
   `usage_recorder_failed` structlog warning instead of disappearing via
   a bare `contextlib.suppress` — the instruction's own text requires
   this ("must emit a safe operational-health signal rather than
   disappear silently"), and the initial commit had stopped masking the
   provider outcome but not yet added the signal.

5. **Finding #11** (`4e6035d`) — a cancelled scheduler submission can
   never execute. A done-callback registered on every accepted item's
   future (before the first `await` after enqueueing, so always attached
   before anything could cancel it) proactively removes it from the
   queue and decrements its pending count the moment cancellation
   happens. `_dispatch_next` itself also refuses to run `coro_factory`
   for an already-cancelled item even in the narrow race where dispatch
   reaches it first, retrying the next queued item on the same
   already-acquired concurrency slot. The starvation-aging scan skips a
   cancelled candidate outright so it can never win the aging tie-break
   ahead of a genuinely still-waiting item.

6. **Finding #12** (`93ab89a`) — real-chain golden fixtures via GitHub
   evidence. New `argus.golden_fixtures` module + `argus fixtures

H. Known bugs found and fixed during this round

- asyncpg `constraint_name` wrapping-depth bug: SQLAlchemy's asyncpg
  dialect exposes `constraint_name` on `exc.orig.__cause__`, not
  `exc.orig` itself as the naive lookup assumed — caught by a real-
  Postgres integration test failure where a legitimate duplicate-key
  collision was being re-raised as "unrecognized" instead of treated as
  idempotent. Fixed via `argus.db.errors.constraint_name()`.
- Replay test event_id reuse: an early version of a replay test reused
